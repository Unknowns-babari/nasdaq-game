# 나스닥 실시간 모의투자

애플, 엔비디아, 마이크로소프트 등 나스닥 대형주 12종목으로 하는 브라우저 주식 시뮬레이션 게임입니다.

- 시작 자금 $100,000, 수수료 0.1%
- 1초마다 시세가 움직이는 실시간 캔들 차트 (캔들 1개 = 15초)
- 속보·루머 뉴스가 몇 초 뒤 시세에 반영
- 1배속 / 4배속 / 15배속, 일시정지
- 진행 상황은 브라우저에 자동 저장

## 플레이

`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속하세요.
