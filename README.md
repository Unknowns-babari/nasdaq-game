# 나스닥 실시간 모의투자

나스닥 100 전 종목(101개 티커)과 주요 ETF 18개(QQQ·SPY·DIA·섹터 ETF 등), 레버리지·인버스 ETF 47개(TQQQ·SOXL·SQQQ·NVDU 등), 급등·테마주 22개로 하는 브라우저 주식 시뮬레이션 게임입니다.

- 시작 자금 $100,000, 수수료 0.1%
- 1초마다 시세가 움직이는 실시간 캔들 차트 (캔들 1개 = 15초)
- 속보·루머 뉴스가 몇 초 뒤 시세에 반영
- 1배속 / 4배속 / 15배속, 일시정지
- 레버리지·인버스 ETF는 게임 안에서 기초자산 움직임의 배수로 움직임
- 비트코인(BTC) 거래와 지수 차트 (시작가: Alpha Vantage 실시간 환율), IBIT·BITU는 비트코인에 연동
- 관심 종목: 하트로 담고 사이드바·'관심' 필터에서 모아 보기
- 지정가·손절 예약 주문 (조건이 맞으면 자동 체결, 사이드바에서 취소)
- 배당·이자: 배당주·배당 ETF·국채를 들고 있으면 10분마다 연 배당률(금리)의 1/4 지급 (게임용 근사치)
- 주요국 국채 12종 거래 (미국·한국·일본·독일·영국·프랑스·이탈리아·캐나다·호주·브라질), 금리 변동에 따라 가격 변동
- 원화 계좌·환율 표시·환전 (시작 환율: 2026-11-26 실제 USD/KRW, 수수료 0.1%)
- 계정: 비밀번호 변경, 회원 탈퇴
- 운영자: 우편 송금·예약 발송, 계좌 초기화, 공지 띠, 사용자 관리
- prices.json: 예약 작업이 매일 실제 종가로 갱신하면 접속 시 자동 반영
- 콜·풋 옵션 매수/청산 (만기 3분·10분·30분, 1계약 = 100주, 만기 자동 정산)
- 진행 상황은 브라우저에 자동 저장

## 로그인

- 아이디와 비밀번호로 회원가입·로그인하면 잔고가 Firebase(Firestore)에 저장되어 어느 기기에서든 이어집니다.
- 한 번 로그인하면 같은 브라우저(크롬 등)로 다시 들어올 때 자동 로그인됩니다.
- 로그인 없이 "체험하기"도 가능하며, 이때는 그 브라우저에만 저장됩니다.
- 코드에 들어 있는 Firebase 설정값은 공개용 값이며, 보안은 Firestore 규칙(본인 데이터만 읽기·쓰기)으로 지킵니다.

## 시세에 대해

- 시작가는 StockAnalysis.com에서 조회한 실제 시세입니다. 나스닥 100은 2026년 11월 26일 목록 기준이고, ETF·테마주는 종목별 페이지의 최근 종가라 날짜가 조금씩 다릅니다.
- 이후 움직임과 뉴스는 게임용 시뮬레이션이며 실제 시장과 다릅니다.
- claude.ai에서 Alpha Vantage 커넥터가 연결된 경우에만 실제 시세를 받아올 수 있습니다. GitHub Pages에서는 시뮬레이션으로만 동작합니다.

투자 조언이 아닌 게임입니다.
